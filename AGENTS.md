# Screenshot Requirements

For every UI/admin/ops change, capture:

1. default state
2. loading state
3. live update state
4. error state
5. empty state, if applicable

Suggested targets:
- admin instance overview
- queue/job monitor
- shared presets UI
- worker diagnostics panel
- unsupported workload failure state

Naming:
- <feature>-before.png
- <feature>-after.png
- <feature>-error.png
- <feature>-empty.png
