Feature 3: Batch Processing — ✅ Complete
  Design Decision:
    Batch processing was NOT implemented as a standalone page. Instead it was
    integrated into existing workflows where it makes UX sense:
    • Browser context menu: batch download, batch reprocess, batch apply preset
    • Upload page: multi-file upload with per-file progress tracking
  Components:
    • src/components/batch/BatchProcessor.vue — Reusable batch queue widget
    • src/components/batch/BatchQueueItem.vue — Per-file status row
    • src/browser/components/BrowserContextMenu.vue — Batch menu items
  API:
    • POST /api/v1/batches — Create batch
    • POST /api/v1/batches/{id}/process — Start batch processing
    • GET /api/v1/batches/{id}/status — Batch progress
