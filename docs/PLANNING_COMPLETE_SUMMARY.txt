Feature 5: Audio-Reactive Video Generator — ✅ Complete
  Page: /audio-visualizer
  Description:
    Upload an audio file, analyse its frequency bands, map each band to
    Deforum animation parameters, and generate audio-reactive AI video.
  Components:
    • src/views/pages/AudioVisualization.vue — Full page view
    • src/components/AudioVisualizer.vue — Three.js live visualizer
    • src/components/audio/AudioVisualizationControls.vue — Controls panel
  Services:
    • src/services/audioDeforumService.js — Offline audio decoding, FFT
      analysis, band extraction, Parseq keyframe generation, Deforum config
    • src/services/audioAnalysisService.js — Real-time waveform/spectrum
  Frequency Bands:
    Sub-bass (20-60 Hz), Bass (60-250 Hz), Low-mid (250-500 Hz),
    Mid (500-2 kHz), Upper-mid (2-4 kHz), Presence (4-6 kHz),
    Brilliance (6-20 kHz)
  Drivable Deforum Parameters:
    translation_x/y/z, rotation_3d_x/y/z, strength_schedule,
    noise_schedule, contrast_schedule, zoom, angle
  Workflow:
    1. Upload audio → offline decode → FFT per frame
    2. Assign bands to Deforum targets with min/max ranges
    3. Preview keyframe schedules (Parseq format: "0:(val), 12:(val), ...")
    4. Export full Deforum config JSON or send to generation pipeline

    now seeks to correct position before calling each action)

   (now checks array_is_list + isset + is_array before accessing prompt[3])

6. src/lib/auth.js — Logout always clears local state
   (setAccessToken(null) and USER_LOGOUT commit run regardless of server
    response to prevent stale auth state on network errors)

   (prevents errors when expected roles don't exist in the database)

8. GeneratorInstanceController URL validation — Stricter regex
   (replaced permissive [\w.\-]+ with RFC-compliant domain label pattern
    that rejects leading dots/hyphens and consecutive dots)

   (DROP + ADD CHECK constraint for pgsql driver alongside MySQL/MariaDB)

10. TransitionPicker — Fixed undefined event in toggle()
    (watch on showPanel called toggle(event) where event was undefined;
